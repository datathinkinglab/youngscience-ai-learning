WORKSHOP RULES

워크숍 진행 3대 원칙: '선(先) 실행 → 후(後) 검증'

실습 원칙

1. 직접 키보드로 입력하고 확인

강사의 시연을 구경하는 것이 아니라, 제공된 프롬프트와 샘플 데이터를 수강생 본인의 ChatGPT 창에 직접 넣어 결과를 확인합니다.

2. 표준안과 대조 피드백

출력된 재무 수치와 계정과목이 사내 회계 기준 및 데이터 원문과 맞는지 체크리스트를 통해 즉시 대조하고 교정합니다.

3. 내 PC에 실행 파일 남기기

대화창 안에만 텍스트를 남겨두지 않고, `.html` 파일로 바탕화면에 저장하여 브라우저 더블클릭으로 바로 구동되는 자산을 챙깁니다.

  1. 좌측 하단 [프로필 이름] 클릭 → [Settings] 이동
  2. [Data Controls] 탭 클릭
  3. [Improve the model for everyone] 토글 버튼을 OFF (비활성화)
  4. 임시 채팅도 사내 데이터 입력·보안 기준 확인 후 활용
✅ Business·Enterprise·Edu 워크스페이스 데이터는 기본적으로 모델 학습에 사용되지 않음. 개인 Plus·Pro는 Data Controls 설정 별도 확인

TECHNICAL CONCEPTS

비개발자를 위한 쉬운 비유: API와 RAG의 본질

개념 이해

API란? (전화 창구)

우리 웹 화면이 OpenAI 서버에게 "이 질문에 답해줘"라고 요청을 보내고 답변을 받아오는 '전화선/창구'입니다.

RAG란? (사전 찾아보기)

AI가 기억에만 의존하지 않고, 질문을 받으면 사내 규정집에서 관련 페이지를 먼저 찾아 읽은 뒤 답하게 하는 방식입니다.

Vector Store (도서관 색인)

수천 장의 사내 문서를 '의미 단위'로 쪼개어, 사용자가 어떤 표현으로 물어보든 관련 규정을 0.1초 만에 찾아내는 색인 저장소입니다.

"오늘 만든 HTML 웹앱은 RAG의 가장 기초적인 원리인 '자료 조회 후 답변'을 로컬에서 구현해본 것입니다."

3. 버튼을 눌러도 반응이 없어요!

원인: AI가 코드 출력 도중 토큰 제한으로 JavaScript 코드가 중간에 잘린 경우입니다.
해결: AI에게 "생략 없이 자바스크립트가 포함된 완전한 전체 코드를 다시 줘"라고 요청하세요.

4. 차트가 안 나타나고 흰 공간만 나와요!

원인: Chart.js 라이브러리 CDN 스크립트 태그가 누락되었거나 인터넷 연결이 끊긴 경우입니다.
해결: 상단에 <script src="...chart.js">가 있는지 확인하세요.
