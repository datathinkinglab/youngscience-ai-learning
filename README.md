# 영사이언스 AI 러닝 허브

공통과정 및 직무별 AI 교육 포털입니다.

- index.html: 메인 페이지
- style.css: 메인 페이지 스타일
- common.html: 공통과정 강의 원본
- management-sales.html: 경영기획·재무 직무교육 (52장)
- instructor-profile.png: 강사소개 캐리커처 원본

추가 강의 HTML을 업로드하고 index.html의 직무 카드에 링크를 연결한 다음 공개 상태와 과정 수를 갱신합니다. main 브랜치에 커밋하면 GitHub Pages가 자동으로 다시 게시합니다.

공통강의는 외부 CDN을 사용하므로 인터넷 연결이 필요합니다.

직무교육은 경영기획/재무 카드에서만 연결됩니다. 영업/마케팅 카드는 준비 중입니다. 공개 카드 기준 2개 과정이 학습 가능합니다.

직무교육 HTML은 기존 CDN을 사용하므로 인터넷 연결이 필요합니다. 교육에서 만드는 No-API FAQ 웹앱의 오프라인 실행 조건과 구분하세요.

이전 대화의 수정본 다운로드 파일은 이 작업에 전달되지 않아, 첨부 원본에 확정된 수정사항을 재적용했습니다. Cloud Instructions / Local AGENTS.md, 업무 목적별 기능 구분, 계산 검증, 데이터 학습 정책, No-API 외부 통신 조건을 반영했습니다.
