# 영사이언스 AI 러닝 허브

공통과정 및 직무별 AI 교육 포털입니다.

- index.html: 메인 페이지
- style.css: 메인 페이지 스타일
- common.html: 공통과정 강의 원본
- management-finance-hr.html: 재무·경영기획·인사 직무교육 (48장). 바이브코딩 개요와 Project → FAQ 웹앱 실습 포함
- management-sales.html: 이전 영업 강의 주소
- management-sales-v2.html: 현재 영업 직무교육
- management-marketing.html: 마케팅 직무교육
- management-rnd.html: 연구개발 관리 직무교육 (48장). 관리 웹앱 제작과 개인 기능 점검
- rnd/: 연구개발 관리 샘플 JSON·TXT, 개인 기능 점검표, 웹앱 완성 예시
- instructor-profile.png: 강사소개 캐리커처 원본
- 실습_샘플데이터/: 강의 상단 메뉴에서 개별 다운로드하는 교육용 가상 파일 4종

추가 강의 HTML을 업로드하고 index.html의 직무 카드에 링크를 연결한 다음 공개 상태와 과정 수를 갱신합니다. main 브랜치에 커밋하면 GitHub Pages가 자동으로 다시 게시합니다.

공통강의는 외부 CDN을 사용하므로 인터넷 연결이 필요합니다.

공통과정과 재무/경영기획/인사, 영업, 마케팅, 연구개발 직무교육 등 총 5개 과정이 학습 가능합니다. 각 직무 카드에서 강의로 이동합니다.

직무교육 HTML은 기존 CDN을 사용하므로 인터넷 연결이 필요합니다. 실습용 CSV와 FAQ는 가상 자료이며 실제 회사 수치나 규정이 아닙니다.
