WORKSHOP RULES

워크숍 진행 3대 원칙: '선(先) 실행 → 후(後) 검증'

실습 원칙

1. 직접 키보드로 입력하고 확인

강사의 시연을 구경하는 것이 아니라, 제공된 프롬프트와 샘플 데이터를 수강생 본인의 ChatGPT 창에 직접 넣어 결과를 확인합니다.

2. 표준안과 대조 피드백

출력된 재무 수치와 계정과목이 사내 회계 기준 및 데이터 원문과 맞는지 체크리스트를 통해 즉시 대조하고 교정합니다.

3. 내 PC에 실행 파일 남기기

대화창 안에만 텍스트를 남겨두지 않고, `.html` 파일로 바탕화면에 저장하여 브라우저 더블클릭으로 바로 구동되는 자산을 챙깁니다.

권장 화면 배치: 좌측에는 프롬프트 교안(또는 슬라이드), 우측에는 ChatGPT Plus 창 & 메모장을 띄워두세요. 준비 완료 시 다음 슬라이드로 이동

VERIFICATION RULES

재무·기획 담당자를 위한 환각(Hallucination) 방어 3원칙

검증 체크리스트
1

수식 근거 요구 (Show Workings)

"결과 숫자만 말하지 말고, 매출원가율 변동 계산에 사용한 분자와 분모, 수식을 명시해줘."

AI가 임의로 반올림하거나 잘못 나눈 수식을 즉시 적발 가능
2

APPENDIX B · TROUBLESHOOTING

부록 B: 비개발자를 위한 HTML 웹앱 문제 해결 가이드

장애 해결
1. 화면에 코드가 그대로 글자로 보여요!

원인: 파일명이 kpi-dashboard.html.txt처럼 끝에 .txt가 붙은 경우입니다.
해결: 탐색기에서 [보기] → [파일 확장명] 체크 후 .txt를 지우세요.

2. 한글이 외계어처럼 깨져서 나와요!

원인: 메모장에서 ANSI나 다른 인코딩으로 저장된 경우입니다.
해결: [다른 이름으로 저장] 창 하단의 인코딩을 [UTF-8]로 지정하고 다시 저장하세요.

3. 버튼을 눌러도 반응이 없어요!

원인: AI가 코드 출력 도중 토큰 제한으로 JavaScript 코드가 중간에 잘린 경우입니다.
해결: AI에게 "생략 없이 자바스크립트가 포함된 완전한 전체 코드를 다시 줘"라고 요청하세요.

4. 차트가 안 나타나고 흰 공간만 나와요!

원인: Chart.js 라이브러리 CDN 스크립트 태그가 누락되었거나 인터넷 연결이 끊긴 경우입니다.
해결: 상단에 <script src="...chart.js">가 있는지 확인하세요.

APPENDIX C · CODE REPAIR

부록 C: 오류 수정 전용 만능 프롬프트 템플릿

수정 템플릿

작성한 웹앱에 오류가 발생했을 때 ChatGPT에게 그대로 전달할 수 있는 수정 템플릿입니다.

오류 디버깅 표준 프롬프트 
현재 작성해준 faq-chatbot.html 파일에서 다음 문제가 발생했어:

- 사용자가 한 행동: [예: 질문창에 '결혼 휴가' 입력 후 엔터]
- 기대했던 결과: [예: FAQ-01 본인 결혼 경조휴가 5일 표출]
- 실제로 발생한 현상: [예: 아무 반응이 없거나 화면에 undefined가 표출됨]

원인을 분석하고 버그를 수정해줘.
외부 서버나 API를 연결하지 말고, 초보자가 브라우저에서 바로 열 수 있는 완전한 단일 HTML 전체 코드를 다시 작성해줘.
수정된 핵심 포인트 2가지도 함께 설명해줘.
