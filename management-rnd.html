학술지 투고 시 AI 워터마크·활용 가이드

AI 사용 범위를 공개하고, 원자료와 실제 검토 기록을 남깁니다.

투고처마다 AI 허용 범위와 선언 방식이 다릅니다. 아래는 실무 요약이며, 제출할 저널의 최신 Guide for Authors를 먼저 확인하세요.

1. 유사도 검사·AI 탐지·워터마크를 구분하기

  • 유사도 검사: 기존 문헌과 겹치는 표현을 찾습니다. AI 사용 여부를 직접 증명하는 검사는 아닙니다.
  • AI 탐지: 텍스트의 특징으로 AI 작성 가능성을 추정합니다. 오탐·미탐이 있어 점수만으로 작성 경위나 부정행위를 확정할 수 없습니다.
  • 워터마크·C2PA: 콘텐츠에 담긴 신호나 서명된 출처 정보를 확인합니다. 적용 여부와 보존 상태는 도구·파일·처리 과정에 따라 다릅니다.

GPT·Claude의 모든 출력에 통계적 워터마크가 있고 모든 투고 시스템이 이를 자동 검출한다고 일반화하지 않습니다. 탐지 도입 여부·방식·판정 기준은 투고처별 확인 사항입니다.

근거: Nature 유사도 검사 · Turnitin 탐지 한계 · C2PA FAQ

2. 저자는 사람이며, AI 사용은 구체적으로 기록하기

AI는 책임을 지는 저자 자격을 충족하지 못하므로 공동 저자로 등록하지 않습니다. 저자는 AI가 만든 부분까지 정확성·인용·연구윤리에 책임집니다. COPE 저자 자격 지침

  • 도구: 사용한 서비스·모델명, 확인 가능한 버전과 사용일을 기록합니다.
  • 목적·범위: 영문 교정, 번역, 초안, 코드, 분석, 그림 중 어디에 얼마나 활용했는지 명시합니다.
  • 사람의 검토: 원문·참고문헌·수치·코드 결과를 대조하고 실제 확인한 내용을 기록합니다.
선언문 위치와 공개 범위 확인 예시
Elsevier
원고 준비에 사용한 AI는 참고문헌 앞 별도 선언문으로 공개합니다. 연구 방법에 사용했다면 Methods에 설명합니다. 단순 철자·문법 점검 등 예외와 해당 저널의 지침을 확인합니다.
IEEE
AI 생성 콘텐츠 사용은 Acknowledgments 공개 지침을 확인합니다. 사용 도구와 적용한 부분·범위를 구체적으로 기록합니다.
Nature Portfolio / Springer Nature
텍스트 작성 보조, 연구 방법, 이미지 활용을 구분해 해당 저널의 AI 정책과 제출 양식을 확인합니다. 하나의 선언 위치·예외를 모든 저널에 적용하지 않습니다.

3. AI 사용 선언문 작성 예시

대괄호를 실제 사용 내역으로 바꾸고 투고처의 지정 형식에 맞춥니다. 아래의 검토·책임 문구는 실제로 검토를 마친 뒤에만 사용합니다.

During the preparation of this work, the author(s) used [TOOL / VERSION] for [PURPOSE AND SPECIFIC SCOPE]. After using this tool, the author(s) reviewed and edited the content as needed and take full responsibility for the content of the published article.

첨부 문서의 선언문 틀을 정리한 예시입니다. 연구 방법·분석·그림에 AI를 사용했다면 별도의 상세 설명이 필요할 수 있습니다.

4. 그림·도표는 사용 허용 여부부터 확인하기

  • 설명 그림·워크플로: 투고처가 허용하는 경우에만 사용하고, 요구하는 캡션·선언문에 도구와 활용 범위를 밝힙니다. 캡션을 달았다고 금지된 사용이 허용되지는 않습니다.
  • 데이터 차트: 실제 원자료와 재현 가능한 분석 결과에서 생성해야 합니다. 값을 만들어 넣거나 결과를 왜곡하지 않습니다.
  • 실험 이미지: 생성 이미지를 실제 관찰·측정 결과처럼 제시하지 않습니다. 원본과 처리 이력, 코드·설정을 보관합니다.
  • 파일·메타데이터: 출처 기록과 제공된 콘텐츠 자격증명을 보존합니다. TIFF·EPS·PNG 또는 C2PA를 모든 학술지의 공통 필수 형식으로 단정하지 않고 투고처 사양을 따릅니다.

그림 유형별 허용 범위 예시: Elsevier 공식 AI 정책

5. 투고 전 개인 점검

  1. 대상 저널의 최신 AI·이미지·저자 지침과 확인일을 기록합니다.
  2. 미공개 원고·고객정보를 승인되지 않은 도구에 입력하지 않습니다.
  3. 필요한 범위만 교정·수정하고 원문, 수정본, 사용 내역을 보관합니다.
  4. 출처·인용·숫자·그림·코드를 직접 검토하고 누락된 선언을 보완합니다.
  5. 기관의 승인된 검사 도구를 사용할 경우 보고서의 근거를 직접 확인합니다. 낮은 탐지 점수가 윤리 준수나 게재를 보장하지는 않습니다.
