01 FACT
기능 (Feature)

제품이 무엇을 하는가?

정량화된 스펙, 프로토콜, 분석 파장, 시약 성분, 처리 용량 등 객관적 사양.

02 VALUE
Benefit

고객에게 어떤 도움이 되는가?

예: 공식 자료로 확인된 시간 단축, 작업 편의성, 오염 리스크 감소 등. 수치는 근거가 있을 때만 사용.

03 EVIDENCE
Claim

검증 가능한 사실인가?

논문 데이터, 공인 인증, 임상 레퍼런스. AI가 허위 데이터를 생성하지 못하도록 통제.

04 ACTION
Marketing Copy

어떻게 쉽게 설득할 것인가?

연구원과 구매담당자의 언어로 기술적 사실을 직관적이고 매력적으로 전달.

실습 1: 광고 콘셉트와 화면 설계

무엇을

광고 콘셉트와 10초 구성표

왜

구도·타이포그래피·장면 전환에 구체적인 기준을 주기 위해서입니다.

어떻게

  1. 사진에 맞는 디자인 방향 선택
  2. 문구·줄바꿈·배치·노출 시간 설계
  3. 도입 → 메시지 → CTA 흐름 확정
완료 기준

디자인 기준과 3장면 구성표

ChatGPT · 같은 대화에서 실행 · 코드 실행 지원 환경
전체 프롬프트 · 스크롤하여 확인
당신은 생명과학 B2B 브랜드의 광고 아트디렉터입니다.
첨부 자료를 바탕으로 10초 무음 모션 광고를 설계해주세요.
이번 단계에서는 기획만 하고 이미지·영상·HTML은 제작하지 마세요.

[입력]
- 브랜드_가드레일.md
- 05_마케팅_제품정보_가상.csv
- YS_CellCare_Auto_200.png

먼저 자료를 실제로 읽고 제품 사진의 크기, 제품 위치, 배경, 문구를 놓을 수 있는 공간을 확인하세요. 접근하지 못한 자료는 명시하고 내용을 추측하지 마세요.

[광고 목적]
- 대상: 바이오 R&D 연구원·연구책임자
- 고객 고민: 주말·야간에도 배양 상태가 마음에 걸리는 상황
- 캠페인 지향점: 연구에 집중하는 내일
- CTA: 제품 데모 문의
- 교육용 가상 제품이며 실제 성능을 홍보하는 광고가 아닙니다.

[아트디렉션]
글자의 크기 대비, 비대칭 구도, 여백, 제품 사진의 배치로 광고의 인상을 만드세요.
“세련되게”, “고급스럽게” 같은 표현만 쓰지 말고 실제 배치·크기·색상·타이밍으로 설명하세요.

다음 두 방향을 비교하고, 첨부 사진에 적합한 방향 하나를 추천하세요.
A. 에디토리얼 제품 광고: 밝은 배경, 큰 남색 헤드라인, 정돈된 제품 사진
B. 타이포그래피 중심 광고: 남색 배경, 큰 흰색 글자, 절제된 청록색 강조

색상은 브랜드 자료가 있으면 우선 적용하세요. 없으면 제안 색상임을 명시하세요.
기본 제안: 남색 #112540, 밝은 회색 #F4F6F8, 강조색 #007F82.
강조색은 핵심 단어와 작은 그래픽에만 사용하세요.

[10초 구성]
0.0–2.6초: 고객 고민
“주말에도,”
“배양이 마음에 걸리나요?”

2.6–6.8초: 캠페인 메시지와 제품
“연구에 집중하는”
“내일.”
제품명 “YS CellCare Auto 200”도 읽을 수 있게 배치하세요.
이 문구는 캠페인 지향점이며 제품 성능 보장이 아닙니다.

6.8–10.0초: 제품명과 문의 행동
“YS CellCare Auto 200”
“제품 데모 문의”
8.0초부터 마지막까지 구도를 고정해 읽을 시간을 확보하세요.

상시 고지:
“교육용 가상 제품 · 실제 제품 성능을 나타내지 않습니다.”

[표현 원칙]
- 한 화면에는 주된 메시지 하나를 두세요.
- 헤드라인·제품명·CTA·고지의 크기와 위치를 구분하세요.
- 제품은 메시지·CTA 장면에서 전체와 받침이 보여야 합니다.
- 도입은 타이포그래피만으로 구성해도 됩니다.
- 원본 사진의 직사각형 배경을 디자인에 포함할 수 있습니다. 배경 제거를 전제로 설계하지 마세요.
- 장면 변화는 글자의 크기·배치와 사진 영역의 변화로 만드세요.
- 제품 작동, 새로운 시점, 가짜 그래프·수치·인증은 추가하지 마세요.

[브랜드 가드레일]
[절대 금지어: 업계 최고, 무조건적인 완벽함, 미확인 임상 결과]
가상 데이터는 실제 제품 성능이나 임상적 효능의 근거가 아닙니다.
성능·효능·비교 주장은 확인 가능한 출처와 시험 조건에 연결하세요.
근거가 없으면 삭제하거나 [근거 확인 필요]로 표시하고 필요한 자료를 정리하세요.
연락처·가격·로고·인증을 임의로 만들지 마세요.

[출력]
1. 추천 콘셉트와 선택 이유
2. 색상·글꼴·글자 크기·여백·정렬 기준
3. 시간 / 정확한 문구와 줄바꿈 / 화면 배치 / 움직임 / 완전히 읽히는 시간 표
4. 첫 장면·메시지 장면·마지막 장면의 구체적인 화면 설명
5. 확인이 필요한 자료

권장 설계 규격은 1920×1080, 16:9입니다. HTML 미리보기는 1280×720으로 비례 축소할 예정입니다.
최종 화면을 640×360으로 줄여 봐도 핵심 문구와 CTA를 읽을 수 있게 설계하세요.

아직 제작하지 않습니다. 키네틱 타이포그래피는 글자의 등장·이동으로 읽는 순서와 강조를 표현하는 방식입니다.

실습 2: 핵심 정지 화면 3장 제작

무엇을

광고의 핵심 정지 시안 PNG 3장

왜

움직임을 더하기 전에 구도와 글자 위계의 완성도를 확보하기 위해서입니다.

어떻게

  1. 도입·메시지·엔드카드 제작
  2. 글자 크기·정렬·여백·제품 비율 확인
  3. 정지 시안을 비교하고 디자인 확정
완료 기준

디자인을 확정한 정지 시안 3장

ChatGPT · 같은 대화에서 실행 · 코드 실행 지원 환경
전체 프롬프트 · 스크롤하여 확인
앞서 추천한 콘셉트로 모션 광고의 핵심 정지 화면 3장을 제작해주세요.
이번에는 정지 시안만 만들고 영상·HTML은 제작하지 마세요.

[시안]
1. 도입: “주말에도,” / “배양이 마음에 걸리나요?”
2. 메시지: “연구에 집중하는” / “내일.” + 제품 사진·제품명
3. 마무리: 제품 사진 + “YS CellCare Auto 200” + “제품 데모 문의”

세 시안 모두 다음 고지를 표시하세요.
“교육용 가상 제품 · 실제 제품 성능을 나타내지 않습니다.”

[제작 방식]
외부 생성 모델·유료 서비스 없이 사용 가능한 코드 실행 기능으로 원본 사진과 정확한 텍스트를 조합하세요.
제품 사진은 재생성하거나 보정하지 마세요. 비율을 유지해 배치하고, 제품 전체와 받침을 보존하세요.
사진의 배경 제거 없이 완성되는 구도를 사용하세요.
한글은 실제 글꼴로 렌더링하세요. 이미지 생성 모델로 글자를 그리지 마세요.

[디자인 기준]
- 1920×1080 기준. 어려우면 1280×720으로 비례 축소하세요.
- 화면 가장자리 안전 여백은 가로·세로 각각 약 6%로 잡으세요.
- 헤드라인은 1920 기준 약 96–144px에서 문장 길이에 맞춰 조정하세요.
- 제품명은 약 44–64px, CTA는 약 40–52px를 출발점으로 사용하세요.
- 고지는 약 28–32px에서 시작하고, 축소 화면에서도 읽히게 조정하세요.
- 수치를 기계적으로 따르지 말고 실제 줄바꿈·겹침·가독성에 따라 수정하세요.
- 한글 글꼴은 실제 사용 가능한 산세리프 계열 하나, 굵기는 2–3개만 사용하세요.
- 큰 글자와 작은 글자, 사진과 여백의 대비를 분명히 만드세요.
- “내일.”은 크기 또는 색상으로 강조하되 나머지 문구와 같은 정렬축을 사용하세요.
- 제품명은 과도하게 줄이지 말고 필요하면 “YS CellCare” / “Auto 200”으로 나누세요.
- CTA는 충분한 여백과 대비가 있는 하나의 명확한 요소로 만드세요.
- 그라데이션은 사진과 배경의 연결에 필요한 경우에만 절제해 사용하세요.

[제외]
과도한 그림자, 유리 효과, 장식용 아이콘, 네온, 입자, 여러 카드와 배지, 가짜 UI, 불필요한 영어 장식 문구.
사진과 문구가 서로 경쟁하거나 제품의 주요 부분을 가리는 배치.

[브랜드 가드레일]
[절대 금지어: 업계 최고, 무조건적인 완벽함, 미확인 임상 결과]
앞서 확인한 브랜드 가드레일을 유지하세요.
새로운 성능·효능·수치·인증·가격·연락처를 추가하지 마세요.
가상 제품의 설정을 실제 성능 근거로 표현하지 마세요.

[자체 검수]
제작한 시안을 실제로 열어 다음을 확인하세요.
- 가장 먼저 읽히는 문구가 의도와 일치하는가?
- 사진·문구·CTA에 공통 정렬 기준이 있는가?
- 글자 크기 대비와 여백이 충분한가?
- 제품 전체·받침·라벨이 보존됐는가?
- 640×360 축소 화면에서도 문구·CTA·고지가 읽히는가?

문제를 발견하면 정지 시안 단계에서 수정하세요.
최종 PNG 3장과 나란히 비교할 수 있는 미리보기, 수정한 점을 제공하세요.
실제로 보지 못한 항목은 “확인 불가”로 표시하세요.
정지 이미지 제작 기능이 없으면 제작 완료라고 하지 말고 구체적인 배치 명세를 제공하세요.

원본 사진과 별도 텍스트를 조합합니다. 배경 제거·제품 재생성 없이 디자인합니다.

  2. 문구 등장·사진 공개·CTA 고정
  3. 한 번 재생하고 필수 항목만 검수
완료 기준

단일 HTML · PNG 3장 · 간단한 검수

ChatGPT · 같은 대화에서 실행 · 코드 실행 지원 환경
전체 프롬프트 · 스크롤하여 확인
앞서 확정한 정지 시안 3장을 기준으로 10초 무음 모션 광고의 HTML 미리보기 1개를 제작해주세요.

[이번 작업 범위]
- 1280×720, 16:9, 10초, 무음
- 원본 이미지를 포함한 단일 HTML 파일
- 대표 화면 PNG 3장과 간단한 검수 결과
- MP4 변환은 하지 마세요.
- 기존 강의 HTML 수정과 웹 배포는 하지 마세요.
- 디자인 대안 추가, 자동 디자인 수정, 반복 재제작은 하지 마세요.

[제작 방식]
사용 가능한 코드 실행 기능으로 HTML/CSS 애니메이션을 사용하세요.
프레임별 이미지를 생성하거나 영상 인코딩 도구를 설치하지 마세요.
